安装包安全

每一个包都不动你的系统关键位置

六个安装包都按最小权限设计，安装与卸载只处理自身文件。

不提权、不写系统目录

Windows 安装版与便携版均为当前用户级（asInvoker），不请求管理员权限、不写系统盘、不改注册表启动项与系统 PATH；macOS 是标准 .app，拖入「应用程序」即可，没有安装脚本。

不自启、不捆绑

不含计划任务、系统服务、浏览器主页/搜索引擎修改，也不捆绑第三方软件；卸载只移除自身文件，不删除你的数据。

系统改动可回滚

自愈修复只改 dsh 配置，改前必生成时间戳备份；声音开关只作用于当前发声的会话，关闭软件自动恢复，不留静音残留。

依赖隔离、可自行校验

Python 依赖只装进 NEXUS 自己的数据目录，不污染全局环境；构建脚本随源码公开，可逐行核对打包行为。未签名版本首次运行可能触发系统提示，属正常现象。
